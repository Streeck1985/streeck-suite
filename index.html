💻 Cómo se está Programando

Detalles del código para la división en 3 islas, animación de ventana y lectura de fuentes de Windows:

Barra Flotante

1. División en 3 Islas / Globos Flotantes

En lugar de una sola caja rectangular, la barra se compone de 3 sub-contenedores (.tb-island) que en modo dividido se separan en 3 cápsulas flotantes independientes con cristal y sombra propia: 

/* Modo 3 Islas Flotantes */
.streeck-taskbar.taskbar-mode-split {
  background: transparent !important;
  box-shadow: none !important;
  border: none !important;
  gap: 14px;
}

/* Cada globo / isla individual */
.streeck-taskbar.taskbar-mode-split .tb-island {
  background: rgba(14, 18, 28, 0.76);
  backdrop-filter: blur(28px) saturate(220%);
  border: 1px solid rgba(255, 255, 255, 0.16);
  border-radius: 22px;
  padding: 7px 14px;
  box-shadow: 0 16px 40px rgba(0, 0, 0, 0.55);
}
Animaciones

2. Animación de Minimizar / Restaurar hacia el Dock

Cuando el usuario minimiza, calculamos la posición del icono en la barra de tareas y aplicamos una transformación que absorbe la ventana hacia él: 

/* Animación de Minimizar hacia la barra */
.active-app-window.minimized {
  transform: translate(-36%, 130%) scale(0.06);
  opacity: 0;
  pointer-events: none;
  filter: blur(10px);
  transition: all 0.38s cubic-bezier(0.16, 1, 0.3, 1);
}

/* Restaurar ventana con rebote elástico */
.active-app-window {
  transition: all 0.42s cubic-bezier(0.175, 0.885, 0.32, 1.275);
}
Fuentes Windows

3. Lector de Fuentes Instaladas en Windows (queryLocalFonts)

Tanto en la web moderna (Chromium/Edge) como en la app nativa de Windows (C# InstalledFontCollection), podemos leer todas las fuentes del usuario: 

// Lectura de fuentes instaladas en la PC del usuario
async function loadInstalledWindowsFonts() {
  if ('queryLocalFonts' in window) {
    const availableFonts = await window.queryLocalFonts();
    const uniqueFamilies = [...new Set(availableFonts.map(f => f.family))];
    
    // Rellenar selector automáticamente con las fuentes de Windows
    populateFontDropdown(uniqueFamilies);
  }
}
DWM Global

4. Aplicación de Aero Glass Global a TODAS las Ventanas y Menú de Inicio

En Windows 11 nativo, el DWM (Desktop Window Manager) controla el fondo de todas las ventanas mediante la API Win32 DwmSetWindowAttribute. Así es como el material elegido se aplica uniformemente a cualquier ventana, barra y menú: 

// C# / Win32 API: Composición de Aero Glass en todas las ventanas
[DllImport("dwmapi.dll")]
public static extern int DwmSetWindowAttribute(IntPtr hwnd, int attr, ref int attrValue, int attrSize);

// DWMWA_SYSTEMBACKDROP_TYPE: 1 = Auto, 2 = None, 3 = Mica, 4 = Acrylic (Aero Glass)
int backdropType = 4; // Acrylic / Aero Glass Frosted
DwmSetWindowAttribute(windowHandle, 38, ref backdropType, sizeof(int));

// Inyectar reflejos especulares y blur en Start Menu y Taskbar
AccentPolicy policy = new AccentPolicy {
    AccentState = AccentState.ACCENT_ENABLE_ACRYLICBLURBEHIND,
    GradientColor = 0x99121828 // Color de tinte translúcido
};

5. Gestión de Batería y Auto-Suspensión en Juegos (Modo Zero-Impact)

Para no restar ni un solo FPS en videojuegos o gastar batería en portátiles, el demonio en C# detecta cuando una aplicación ocupa la pantalla completa (DirectX / Vulkan / Media) y congela completamente el bucle de renderizado: 

// C# / Win32: Detección inteligente de Pantalla Completa (Juegos o Películas)
public void MonitorFullScreenApps() {
    IntPtr foregroundHwnd = GetForegroundWindow();
    GetWindowRect(foregroundHwnd, out RECT rect);
    Screen screen = Screen.FromHandle(foregroundHwnd);

    bool isFullScreen = (rect.Width == screen.Bounds.Width && rect.Height == screen.Bounds.Height);

    if (isFullScreen && !isGameModeSuspended) {
        // Pausar render loop, siluetas 3D, blur hooks y animaciones
        CompositionTarget.Rendering -= RenderLoop;
        EventBus.Publish("SYSTEM_IDLE_SUSPEND", true);
        isGameModeSuspended = true; // Consumo CPU: 0.0% | VRAM liberada
    } else if (!isFullScreen && isGameModeSuspended) {
        // Reanudar inmediatamente al volver al escritorio
        CompositionTarget.Rendering += RenderLoop;
        EventBus.Publish("SYSTEM_IDLE_SUSPEND", false);
        isGameModeSuspended = false;
    }
}
